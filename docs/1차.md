# 제목

CNC 설비 고장 예측 모델 비교 (Random Forest, XGBoost, LightGBM)

---

# 상세

UCI AI4I 2020 Predictive Maintenance Dataset을 이용하여 `Machine failure`를 예측하는 이진분류 모델을 구현하였다.

`Machine failure`는 정상(0)과 고장(1)으로 구분되며, 전체 10,000건 중 고장 데이터는 339건(3.39%)에 불과하다. 정상 데이터와 고장 데이터의 비율이 약 **9661 : 339**로 불균형하기 때문에 Accuracy만으로 모델을 평가하면 고장 탐지 성능을 제대로 확인하기 어렵다.

---

## 1. 데이터 전처리

전처리는 다음 순서로 진행하였다.

- CSV 컬럼명과 `Type` 값의 앞뒤 공백 제거
- 식별자 컬럼인 `Product ID` 제거
- `Type` 컬럼을 One-Hot Encoding으로 변환
- 타깃 변수로 `Machine failure`를 설정
- 입력 변수에서는 `Machine failure`과 세부 고장 모드(`TWF`, `HDF`, `PWF`, `OSF`, `RNF`)를 제외
- 학습 데이터와 테스트 데이터를 8:2로 분할
- `stratify=y`를 적용하여 학습·테스트 데이터의 정상/고장 비율 유지
- MinMaxScaler를 사용하여 모든 연속형 입력 변수를 0과 1 사이로 정규화(Scaling) 적용

사용한 주요 입력 변수는 대기 온도, 공정 온도, 회전 속도, 토크, 공구 마모도, 제품 등급 원-핫 인코딩 변수이다.

---

## 2. 클래스 불균형 처리

학습 데이터의 고장 샘플 부족 문제를 해결하기 위해 Random Forest 학습 시 SMOTE를 적용하였다.

SMOTE는 기존 고장 데이터를 단순히 복사하지 않고 소수 클래스 주변의 새로운 샘플을 생성하여 학습 데이터의 클래스 균형을 맞추는 방법이다.

추가로 Random Forest에는 `class_weight="balanced"`를 적용하여 고장 클래스의 중요도를 높였다.

Random Forest의 고장 확률 예측값은 기본 임계값 0.5 대신 **0.3**을 사용하였다. 이는 정상으로 분류되는 고장 데이터를 줄여 고장 탐지 Recall을 높이기 위한 설정이다.

---

## 3. 모델 구성

다음 세 가지 분류 모델을 비교하였다.

- Random Forest
  - `n_estimators=500`
  - `max_depth=15`
  - `min_samples_leaf=2`
  - SMOTE와 `class_weight="balanced"` 적용
  - 고장 확률 임계값 0.3 적용
- XGBoost
  - `n_estimators=300`
  - `learning_rate=0.05`
  - `max_depth=5`
  - 기본 예측 임계값 0.5 사용
  - SMOTE를 적용하지 않은 원본 학습 데이터 사용
- LightGBM
  - `n_estimators=300`
  - 기본 예측 임계값 0.5 사용
  - SMOTE를 적용하지 않은 원본 학습 데이터 사용

모든 모델은 `random_state=42`를 사용하였다.

---

# 결과

## 성능 비교

| 모델 | Accuracy | 고장 Precision | 고장 Recall | 고장 F1-score |
| --- | ---: | ---: | ---: | ---: |
| Random Forest + SMOTE | 0.9455 | 0.37 | **0.85** | 0.52 |
| XGBoost | 0.9825 | 0.85 | 0.59 | 0.70 |
| LightGBM | **0.9845** | **0.89** | 0.62 | **0.73** |

## 혼동행렬 결과

| 모델 | 정상 정분류 | 정상 오분류 | 고장 미탐지 | 고장 정탐지 |
| --- | ---: | ---: | ---: | ---: |
| Random Forest + SMOTE | 1,833 | 99 | 10 | **58** |
| XGBoost | 1,925 | **7** | 28 | 40 |
| LightGBM | **1,927** | **5** | 26 | 42 |

결과를 해석하면 다음과 같다.

- LightGBM은 Accuracy, 고장 Precision, 고장 F1-score가 가장 높았다.
- Random Forest는 고장 Recall이 0.85로 가장 높아 실제 고장을 놓치는 비율이 가장 낮았다.
- Random Forest는 고장 탐지를 많이 수행한 대신 정상 데이터를 고장으로 판단한 경우가 99건으로 가장 많았다.
- XGBoost와 LightGBM은 정상 오분류가 적어 높은 Precision을 보였지만, 일부 고장 데이터를 정상으로 판단하였다.
- 정상 데이터가 많은 불균형 데이터에서는 Accuracy만으로 모델을 선택하면 고장 탐지 성능을 놓칠 수 있으므로 Precision, Recall, F1-score를 함께 비교해야 한다.

---

# 해결

불균형한 CNC 설비 고장 데이터를 대상으로 세 가지 모델을 비교한 결과, 목적에 따라 모델을 선택할 수 있다.

- 전체적인 분류 성능과 고장 판정의 신뢰도를 중시하는 경우: **LightGBM**
- 고장 누락을 최소화해야 하는 예지보전 환경: **Random Forest + SMOTE**
- 정상 설비를 고장으로 잘못 판단하는 비용이 큰 경우: **LightGBM 또는 XGBoost**

최종적으로 일반적인 성능 기준에서는 LightGBM을 우선 모델로 선택한다. 다만 실제 설비 운영에서는 고장을 놓치는 비용이 크므로 Random Forest의 Recall 0.85 결과도 함께 고려해야 한다.

향후에는 ROC-AUC와 PR-AUC를 추가하고, 예측 임계값별 Precision·Recall 변화를 비교하여 실제 운영 목적에 맞는 임계값을 결정할 필요가 있다.
