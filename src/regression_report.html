Tool Wear 회귀분석 보고서

공정 센서와 제품 등급 정보를 이용해 공구 마모 시간(Tool wear)을 예측하고, 네 가지 회귀 알고리즘의 성능을 동일한 조건에서 비교했습니다.

1. 데이터 요약

관측치10,000행
변수14개
결측치0건
중복 행0건

목표 변수: Tool wear [min]

범위는 0~253분, 평균은 107.95분, 중앙값은 108분입니다. 0분인 관측치는 120건이며, 분포는 전체 범위에 비교적 고르게 퍼져 있습니다.

Tool wear 분포와 수치형 변수별 피어슨 상관계수

2. 분석 설계

설명 변수 5개 선택
학습 80% / 테스트 20%
전처리 파이프라인 적용
네 모델 동일 조건 평가

설명 변수

제품 등급(Type), 대기 온도, 공정 온도, 회전 속도, 토크를 사용했습니다. 고장 결과 변수와 고장 유형 플래그는 예측 시점 이후의 정보가 섞일 가능성이 있어 제외했습니다.

전처리

수치형 변수에는 중앙값 결측치 처리와 StandardScaler 표준화를 적용했습니다. 범주형 Type에는 최빈값 처리와 원-핫 인코딩을 적용했습니다. 전처리기는 학습 데이터에만 적합해 데이터 누수를 방지했습니다.

3. 모델 성능 비교

모델R²MAE (분)RMSE (분)MAPE

XGBoost0.059453.965363.3690213.57%

지표 단위: MAE와 RMSE는 백분율이 아니라 목표 변수와 같은 분(min) 단위입니다. MAPE만 백분율입니다.

R²는 높을수록, MAE·RMSE·MAPE는 낮을수록 우수합니다.

4. 실제값과 예측값

붉은 점선에 가까울수록 정확한 예측입니다. 네 모델 모두 예측값이 평균 주변에 집중되는 경향을 보입니다.

5. 결론과 해석

  • Random Forest가 네 지표를 종합했을 때 가장 우수하지만, R²가 0.0685로 설명력은 낮습니다.
  • 사용한 센서 변수와 Tool wear의 개별 상관계수가 거의 0에 가까워 현재 특성만으로 정밀한 예측이 어렵습니다.
  • 선형회귀와 SVR의 R²가 음수이므로 테스트 데이터에서 목표 변수의 평균을 사용하는 단순 예측보다도 성능이 낮습니다.
  • MAPE는 실제값이 0인 행을 제외해 계산했지만, 1~수 분의 작은 값이 남아 있어 200% 이상으로 크게 왜곡됩니다.
  • 실무 판단에는 MAE와 RMSE를 우선 사용하고, MAPE는 WAPE 또는 SMAPE와 함께 해석하는 것이 적절합니다.
